# 교실 도구함 + 로컬 일기장

별도 패키지 설치 없이 Node.js로 실행할 수 있습니다.

macOS에서는 `start.command`를 더블 클릭하면 허브 서버가 실행됩니다. 로그인 중에는 서버가 계속 실행됩니다. 처음 실행 시 macOS가 확인을 요청할 수 있습니다.
처음 한 번은 `launchd.plist.example`을 `com.deok.teacher-hub-local.plist`로 복사하고, 파일 안의 경로를 이 폴더의 실제 경로로 바꿔 주세요.

```bash
npm start
```

브라우저에서 `http://127.0.0.1:4173` 주소를 열어 사용하세요.

- 허브: `http://127.0.0.1:4173/` (자리 바꾸기, PDF 글자 수 세기, 생활기록부 개인정보 가리기, 일기장)
- 일기장: `http://127.0.0.1:4173/diary/`
- 일기 데이터: `data/entries.json`

`entries.json` 파일을 복사해 백업하거나 다른 컴퓨터로 옮길 수 있습니다. 서버가 실행 중일 때는 일기장을 통해서만 내용을 수정하는 것이 안전합니다.
